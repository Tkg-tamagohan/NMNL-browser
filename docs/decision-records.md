# 決定記録

要件定義書の要協議事項に対する確定内容を記録する。
確定済みの決定は要件定義書本文へも反映済みとする。

| ID | 項目 | 決定内容 |
|----|------|----------|
| A | UI 基盤 | egui/eframe を採用する |
| B | 対象 OS | Windows と Linux とする(macOS は将来の拡張候補) |
| C | MVP のカラム構成 | main、tl、notifications、mentions、channel の各カラム(チャンネルカラムは必須) |
| D | MFM 対応範囲 | 太字、斜体、取り消し線、コード、引用、リンク、メンション、ハッシュタグ、カスタム絵文字を描画し、関数記法と HTML 系タグは除去して本文のみ表示 |
| E | ノート操作の範囲 | 返信、リノート、引用、リアクション、投稿(投票、編集、削除は対象外) |
| F | 動画と音声 | 内蔵再生せず、クリックで外部ブラウザを開く |
| G | リアクション UI | 初版からカスタム絵文字ピッカー(検索付き)を実装する |
| H | リポジトリと名称 | Tkg-tamagohan/NMNL-browser(No Misskey No Life の略称)、ライセンスは MIT |
| I | 軽量さの目標値 | コールド起動 2 秒以内、アイドル時メモリ 150 MB 以内、単一バイナリ 30 MB 以内 |
| J | UI 言語 | 日本語のみ |
| K | トレイ常駐 | トレイ最小化あり |

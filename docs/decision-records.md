# 決定記録

要件定義書の要協議事項に対する確定内容を記録する。
確定済みの決定は要件定義書本文へも反映済みとする。

| ID | 項目 | 決定内容 |
|----|------|----------|
| A | UI 基盤 | egui/eframe を採用する |
| B | 対象 OS | Windows と Linux とする(macOS は将来の拡張候補) |
| C | MVP のカラム構成 | main、tl、notifications、mentions、channel の各カラム(チャンネルカラムは必須) |
| D | MFM 対応範囲 | 太字、斜体、取り消し線、コード、引用、リンク、メンション、ハッシュタグ、カスタム絵文字を描画し、関数記法と HTML 系タグは除去して本文のみ表示 |
| E | ノート操作の範囲 | 返信、リノート、引用、リアクション、投稿(投票、編集、削除は対象外) |
| F | 動画と音声 | 内蔵再生せず、クリックで外部ブラウザを開く |
| G | リアクション UI | 初版からカスタム絵文字ピッカー(検索付き)を実装する |
| H | リポジトリと名称 | Tkg-tamagohan/NMNL-browser(No Misskey No Life の略称)、ライセンスは MIT |
| I | 軽量さの目標値 | コールド起動 2 秒以内、アイドル時メモリ 150 MB 以内、単一バイナリ 30 MB 以内 |
| J | UI 言語 | 日本語のみ |
| K | トレイ常駐 | トレイ最小化あり |
| L | 画像の表示レイアウト | 添付枚数に応じたグリッド(1 枚は全幅で高さ上限つき、2 枚は横 2 分割、3 枚は左大 1 枚と右 2 枚、4 枚以上は 2 列)とする |
| M | 小さい原本画像の拡大 | セルいっぱいまで拡大し、高さに上限を置く(上流公式の `object-fit: contain` 相当。上限目安は高さ 360 ピクセル前後で実装時に調整) |
| N | インライン表示の画像 URL | `thumbnailUrl` を優先し、未設定時は `url` にフォールバックする |
| O | リモートホスト絵文字バッジのクリック | 同名のローカル絵文字があれば `:name@.:` でトグルし、無ければ表示のみ(mk-go の「相乗り」方式) |
| P | チャンネル名の表示形態 | カード左端にチャンネル色のバーを描き、ノート下部(リアクション行の上)にアイコンつきチャンネル名を置く |
| Q | チャンネル名のクリック | そのチャンネルの channel カラムを開く(既存があれば差し替え) |
| R | チャンネル名の表示範囲 | 全カラムと会話ビューで表示し、当該チャンネルの channel カラム内では省略する |
| S | 画像ビューアのクローズ操作 | Esc キーとマウスの戻るボタンで閉じる。既存の × ボタンと ←→ キーの画像送りは維持する |
| T | 文字サイズの調整方式 | UI 全体を拡縮する(文字だけでなくボタンや画像も連動)。ユーザー名や本文など要素ごとの個別設定は実装が軽い場合に限り設け、重い場合は残課題とする |
| U | 文字サイズの調整 UI と範囲 | 設定画面のスライダーによる連続値(0.8〜1.5 倍、既定 1.0)で、設定を保存して起動時に復元する |
| V | チャンネル投稿の選択 UI | 投稿フォーム内のチャンネル選択(フォロー中一覧と検索)と、channel カラムの「このチャンネルに投稿」導線の両方を設ける |
| W | チャンネル投稿の公開範囲と対象ノートの継承 | チャンネル選択時は公開範囲をパブリックに固定しダイレクトは不可。対象ノートがチャンネル所属のとき返信、引用、リノートは `channelId` を継承して同じチャンネルへ投稿する(上流動作の推測に基づき実装時に io で検証) |
| X | メインカラムの投稿フォーム形態 | 投稿フォームはメインカラムに置き、メインカラム未配置のときだけボトムパネルのフォームを自動表示する |
